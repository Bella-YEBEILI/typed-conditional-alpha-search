# GPlearn3D

Welcome to GPlearn3D project! The primary objective of this project is to enhance the existing gplearn package and enable three-dimensional structured dimension genetic programming (GP) specifically for cross-sectional factor investigation.

## Project Overview

The original version of the gplearn package only supported 2-dimensional data input, thus leading to limited use cases, such as CTA and single-underlying asset factor mining scenarios. The modified verison adapts to 3D data input with shape [trade_date, features, ts_code], generated by functions `make_3d` or `make_XY`, expanding the usage of gplearn package to multi-asset cases. 

Note that the original version only supports "mean squared error" and "cross entropy" as fitness metrics and arithmetic operators such as "add" and "sqrt" as functions. However, with this update, we have introduced significant improvements to extend its functionality and empower factor analysis. The key enhancements in this version include:

### Expanded Fitness Metrics

We have incorporated a range of additional fitness metrics to complement rankIC. These new metrics include ICIR, quantile returns and monotonicity. By incorporating these metrics, we can conduct a more comprehensive evaluation of factors, leading to improved GP performance.

### Enhanced Base Operators

The modified package now offers an expanded set of base operators, including both time series and cross-sectional capabilities. This enhancement provides increased flexibility, empowering researchers and practitioners to conduct more effective cross-sectional factor analysis. More operators (ts_residual, ts_cov, normalization, standardization, etc.) are coming.

Moreover, the function parameters are now allowed to inherit automatically, unlike the original version which required specifying fixed parameters such as rolling window. Besides, some of the operators are optimized and accelerated by numba.

## Getting Started

To get started with GPlearn3D, follow these steps:

1. Import the necessary modules and functions required for factor analysis.
2. Specify your desired fitness metrics, including rankIC, quantile returns, monotonicity, and correlation within factors.
3. Define and prepare your data inputs for analysis.
4. Run the genetic programming algorithm using the provided functions and operators.
5. Evaluate and interpret the results to gain insights into your cross-sectional factors.

For more detailed instructions and examples, please refer to the documentation (gplearn3d demo.ipynb) provided in the repository.
